## Cenário

O projeto busca auxiliar estudantes na organização de suas atividades acadêmicas, permitindo visualizar tarefas, prioridades e andamento das atividades em um único sistema.

## Produto

Escolhemos o **Caminho B**, que consiste no desenvolvimento de um sistema ou site com lógica de funcionamento.

O projeto será desenvolvido como um sistema web de pequeno porte, priorizando a organização do processo de desenvolvimento e o acompanhamento das atividades do grupo.

## Funcionalidades

O sistema terá inicialmente as seguintes funcionalidades:

1. Cadastrar uma nova tarefa.
2. Visualizar as tarefas cadastradas.
3. Alterar o status de uma tarefa.
4. Organizar tarefas por prioridade ou situação.
5. Visualizar as tarefas concluídas.
